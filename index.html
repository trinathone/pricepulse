PricePulse

Track product prices, get alerted the moment they drop below your target.

PricePulse watches Amazon/eBay listings on a schedule, records every price it sees, and fires an alert when a product crosses your target price. This page is a static preview of the tracker UI — the full app is a FastAPI service with a live scraper, SQLite history, and a REST API (see the source + full README for the real API, run locally with python main.py).
